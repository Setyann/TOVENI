# TOVENI — Contemporary Furniture Website

TOVENI is a fictional contemporary furniture brand created as a commercial web development portfolio project.

The website presents a modern furniture company based in Yerevan, combining ready-to-order collections, configurable furniture, custom-made solutions, and services for private clients, designers, and businesses.

## Live Demo

**Website:** https://setyann.github.io/TOVENI/

## Features

* Responsive furniture catalog
* Product search, filtering, and sorting
* Detailed product views
* Interactive product configuration
* Dynamic pricing based on selected options
* Materials, finishes, and size selection
* Favorites system
* Inquiry list
* Furniture order request flow
* Custom furniture request form
* Residential project showcase
* Designer / Trade program
* B2B furniture solutions
* Showroom information
* Contact section
* FAQ
* EN / HY / RU interface
* Light and dark themes
* LocalStorage for preferences and demo interactions
* Responsive desktop, tablet, and mobile layouts

## Product Configuration

Selected products include an interactive configurator that allows users to choose available options such as:

* Size
* Configuration
* Wood finish
* Fabric group
* Material
* Legs and additional options

The displayed price updates dynamically according to the selected configuration.

## Inquiry & Order Experience

Visitors can save products to favorites, add configured products to an inquiry list, and complete a structured order request.

The project also includes separate inquiry flows for:

* Custom-made furniture
* Interior designers
* Commercial and B2B projects

All forms are frontend demonstrations. No information is transmitted to a real business or backend server.
